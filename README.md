# Justus Mugo Career Portfolio

## Files
- index.html — complete frontend
- style.css — design and responsive layout
- script.js — mobile menu, scroll effects and contact form behavior
- images/justus-profile.png — professional profile image

## Run in VS Code
Open this folder in Visual Studio Code and open `index.html` with Live Server,
or double-click `index.html` to preview it in a browser.

The CV buttons are placeholders for now. Add your final CV PDF and connect the
buttons to it after we finish the frontend.
